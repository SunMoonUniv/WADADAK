# 공개 코스 고스트 재생·시작 승인 — 2026-10-27

기준: 정책 공통 6, 고스트 9.1~9.6, 개발 정책 v3의 모듈 공개 인터페이스·쓰기 트랜잭션 경계. 타인의 공개 **등록 코스 완주 기록**에 기존 대결 준비·시작 승인·상대 고정 경로를 연결했다. 휴대폰 재생 검증 뒤 사용자 요청으로 테스트 전용 미리보기와 생성 도구를 제거했다. 내 자유 기록의 1,000m·중단 허용은 기존 9.6대로 유지하며 타인의 자유 기록으로 확대하지 않는다.

## 앱에서 사용하는 흐름

1. 코스 상세 정보/리뷰(B1/B8)는 전체 기간, 랭킹 탭/전체 순위(B9/G3)는 고른 기간의 공개 고스트 CTA를 누른다. 후보 없음·로딩·오류는 비활성화한다.
2. `/run/public-ghost`에서 선택한 공개 상대를 검증하고 기존 코스를 준비한 뒤 **달리기 탭의 고스트 대결 준비로 바로 이동**한다. 확인 중에는 로딩, 실패하면 재확인·뒤로 가기를 제공한다. 테스트용 재생 화면·배속·슬라이더·추가 선택 버튼은 없다.
3. 기존 준비 화면의 `선택한 공개 기록` 카드에서 상대 시간과 공개 코스 기록임을 확인한다. `내 완주 기록으로 변경`은 기존 본인 기록 선택으로 연결한다. 준비·선택은 측정·시작 승인·도전 수를 만들지 않는다.
4. 기존 출발점·권한 확인→1초 누르기·3초 카운트다운→서버 시작 승인→기기 저장·실제 측정→지도 고스트/격차→서버 결과를 사용한다. 같은 상대·선택 기간의 60초 재개를 재사용한다.

계정·코스 변경 및 화면 종료 뒤의 늦은 응답은 버린다. 이미 진행 중이거나 시작 확인 중이면 기존 달리기로 복귀한다. 사용할 수 없어진 상대를 다른 기록으로 자동 교체하지 않는다. 기존 달리기→고스트 대결→내 완주/내 자유 기록 선택 경로도 유지한다. 공개 기록 API는 실제 대결의 파생 재생 자료 확보에 계속 사용한다.

## API와 재검증

| 요청 | 동작 |
| --- | --- |
| `GET /api/v1/runs/records/{sourceId}/public-ghost-playback?courseId={id}&period=ALL` | 로그인 필수. `publicPeriod`, 공개 `candidate`, 파생 `playback`, 원본 `sourceCourseVersion` 반환. 기간은 ALL/MONTH/WEEK, 생략하면 ALL |
| `POST /api/v1/runs/sessions/{id}/ghost/start` | 기존 `courseId`, `courseVersion`, `sourceRecordId`, `startedAt`, `playbackVersion`에 선택 `publicPeriod`를 추가. 값이 있으면 공개 상대 검증, null이면 기존 본인 경로 |
| `GET /api/v1/runs/sessions/{id}/ghost/start` | 본인에게 저장 승인 반환. 공개 상대가 나중에 삭제·비공개되거나 랭킹 조회가 실패해도 이미 저장된 승인을 유지 |

공개 준비·새 시작마다 `RankingApi.findPublicGhostCandidate`로 **선택한 원본 ID**가 그 기간의 현재 공개 대표인지 확인한다. 본인·비공개·탈퇴·삭제·숨긴 코스·다른 기간은 허용하지 않는다. 상위 10개 목록으로 재검증을 대신하지 않으므로 직접 선택된 11위 이하도 같은 기준으로 검사한다. 기간 기준은 기존 `registeredAt`·Asia/Seoul, 공개 순위와 대표 선정 방식은 유지한다.

기존 본인 기록 상세·원본 입력·본인 재생 API의 소유권은 완화하지 않는다. 전용 API는 공개 코스 기준 경로와 파생 누적 위치/시간·정지/공백·품질 자료만 제공한다. 원본 GPS 입력 스트림·개인 지표·프로필 전체를 복사하거나 공개하지 않는다.

원본은 서버 처리 DONE·완주·시간 재현·자기 원본 경로 버전과 품질을 기존 builder로 확인한다. GPS 10초 초과 연결 금지, 수동 정지 제외 원본 공백 최대 30초·누적 5%를 유지한다. 평균 페이스로 이동을 합성하지 않는다.

## 경로 버전과 저장·경합

`CourseApi`·`RankingApi` 조회는 run 쓰기 트랜잭션 밖이다. 공개 승인 쓰기는 두 회원 ID 정렬 잠금→시도 세션→원본 세션 순서로 진행한다. 회원 공개 변경은 run 소유 `member_visibility_copies`에 큰 이벤트 버전만 반영하며 탈퇴 후 지연 이벤트로 되살리지 않는다. 시작 전 원본 삭제/탈퇴/비공개 차단, 원본 적합성 검증·상대 자료 저장·기존 코스 시작·집계 이벤트는 같은 트랜잭션이다. 양방향 대결의 잠금 경합을 검증했다.

코스의 엔티티 버전은 유지 기간 연장·메타데이터 변경으로도 증가한다. 공개 원본은 원래 버전으로 재현한 뒤 현재 코스와 **코스 ID·순서 있는 전체 경로·정수 거리**가 모두 정확히 같을 때만 현재 준비 버전에 맞춘 파생 기준 자료를 사용한다. 경로가 바뀌었으면 차단한다. 원본 JSON은 덮어쓰지 않고 원본 버전은 `source_course_version`에 별도 보존한다. 기존 내 코스 고스트의 엄격한 버전 비교는 바꾸지 않았다.

같은 세션의 동일 요청은 저장 승인·상대·기간을 그대로 반환하며 코스 시작 이벤트를 추가하지 않는다. 기간 또는 본인/공개 경로를 바꾼 요청은 충돌이다. 승인 뒤에는 현재 랭킹·공개·원본 상태에 의존하지 않고 고정 자료로 기존 판정에 연결한다. 별도 만료·30일 고스트 삭제는 없다. 본인 삭제/탈퇴는 기존 연쇄 삭제를 따른다.

DB: `V20261027_2200__run_public_ghosts.sql`(`public_period`, 합법적 legacy 계산 버전 null, 회원 공개 복사본), `V20261027_2300__run_public_ghost_source_version.sql`(원본 코스 버전). 이미 적용한 파일을 수정하지 않고 후속 마이그레이션을 사용한다. 상세 스키마는 루트 DB 문서를 따른다.

## 테스트 정리와 반영 범위

앞선 로컬 휴대폰 검증에서 사용자 등록 선문대 코스에 합성 완주를 생성해 네이버 지도 재생을 확인했다. 이후 사용자 요청으로 **합성 계정·완주 기록은 삭제**하고 `PublicGhostDemo`와 `seedPublicGhostDemo` 생성 명령을 제거했다. 기록은 기존 삭제 서비스와 이벤트로 정리해 로컬 랭킹에서도 제외했다. 사용자가 만든 선문대 코스는 유지했다.

테스트 전용 화면은 제거했지만 실제 기능 회귀 검증은 유지한다. 이번 반영은 기존 프로젝트 코드의 대결 흐름 수정이며 공용 서버 배포·main 머지·커밋·푸시·PR 변경은 포함하지 않는다. 앞선 휴대폰 설치본의 미리보기 검증을 이번 직접 진입 흐름의 설치·야외 인수로 간주하지 않는다.
