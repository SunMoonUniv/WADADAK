# 달리기 검증 기록 템플릿

[전체 안내](README.md)

이 문서를 복사해 주차별 실제 기록을 작성한다. 체크 항목은 증거가 있을 때만 완료로 바꾼다. 원본 좌표·토큰·비밀번호는 일반 로그/공개 문서에 넣지 않는다. 필요 자료는 비식별 합성 샘플과 접근이 제한된 증거 위치로 연결한다.

## 3. 시나리오 기록

각 시나리오를 아래 형식으로 복사해 작성한다. 개발 계획의 인수 시나리오는 빠짐없이 포함한다.

| 항목 | 내용 |
| --- | --- |
| 시나리오 ID·이름 | 예: W03-response-lost |
| 검증 종류 | 단위 / 실제 DB 통합 / 앱 연결 / 실기기 |
| 선행 상태·자료 | 세션 상태·샘플 버전·계정 영역·기기 조건 |
| 재현 순서 | 실행한 조작을 순서대로 기록 |
| 기대 결과 | 원본/순번·시간·거리·상태·레코드 수·화면 |
| 실제 결과 | 측정값·응답·기기/서버 상태 |
| 증거 | 테스트 결과·비식별 비교 자료·화면/재현 기록 위치 |
| 판정 | 미실행 / 통과 / 실패 |
| 실패 원인·담당·다음 행동 | 작성 |
| 재검증 빌드·결과 | 작성 |
| 검토자 확인 | 작성 |
