# 달리기 완료 기준 추적표

작성일: 2026-10-08 · 초기 상태: 전 항목 미실행

[전체 안내](README.md) · [검증 기록 템플릿](검증-기록-템플릿.md) · [개발 계획](../달리기%20기능%20개발%20계획%20-%202026-10-08.md)

이 표는 주차별 진행과 개발 계획의 인수 시나리오 22개를 연결한다. 아래 기대 결과는 개발 계획에서 가져왔으며, 표를 만들었다는 이유로 개발·테스트가 완료된 것은 아니다.

## 1. 사용 순서

1. 이번 주 가이드의 진입 조건을 확인하고 아래 주간 상태를 진행으로 바꾼다.
2. 해당 주차의 T 번호를 선택하고 검증 기록 템플릿을 복사해 재현 순서·빌드·자료를 작성한다.
3. 기대 결과와 실제 값·상태를 비교한다. 상태는 미실행 / 통과 / 실패로 기록한다.
4. 증거 칸에 실행 기록·테스트 결과·PR 위치를 연결한다. 테스트 이름이나 체크 표시만으로 통과 처리하지 않는다.
5. Android/iOS가 모두 필요한 항목은 기록 안에 플랫폼별 결과를 분리한다. 한 플랫폼만 통과하면 해당 항목 전체를 통과로 세지 않는다.
6. 다른 한 명이 증거를 확인한 뒤 주간 가이드의 필수 항목도 함께 검토한다.
7. 최종 빌드에서 기존 증거가 유효한지 확인하고 모든 필수 항목을 통과했을 때 전체 완료로 판정한다.

정책 제4부 4.2의 미합의 동작은 [전체 안내](README.md)의 가정을 따른다. 합의 전에는 변경 동작을 구현 완료로 세지 않는다. 기존 정책 유지로 계획이 바뀌면 기준 문서·주간 가이드·이 표를 함께 정렬한다.
