러닝 중 페이지는 지도 → 기본 지표 → 전체 지표 순서이며, 처음에는 가운데 기본 지표를 표시한다. 준비 화면에서만 하단 탭을 표시한다. 카운트다운·측정·정지·결과는 전체 화면으로 표시하고 결과 확인 뒤 준비 화면으로 돌아온다.

## 코드 읽는 순서

1. `FrontEnd/app/lib/features/run/presentation/free_run_screen.dart`: 상태에 따라 화면을 고르고 1초 누르기·종료 확인을 연결한다. 준비 화면과 카운트다운이 들어 있다.
2. `free_run_live_view.dart`: 좌우 슬라이드와 공통 정지·재개 버튼을 구성한다.
3. `free_run_result_view.dart`: 동일한 세션의 총 소요시간·달린시간·정지시간을 보여준다.
4. `FrontEnd/app/lib/main_shell.dart`: 러닝 상태에 따라 하단 탭 표시 여부만 결정한다. 탭 또는 경로 이동으로 측정 엔진을 버리지 않는다.

기존 `wadadak_design_system`의 토큰, Pretendard 글꼴, 버튼, 아이콘, 시간, 지표, 카드, 센서 상태, 페이지 표시 점을 재사용했다. 공통 컴포넌트 변경은 러닝 헤더의 세로 가운데 정렬, 지표 라벨 스타일 선택 옵션, 좁은 화면의 하단 탭 너비 조정이다. 기존 지표의 기본 스타일과 402px 하단 탭 배치는 유지한다.

준비 카드의 러닝 아이콘은 피그마 원본 `1453:4155`의 26×24 SVG를 `FrontEnd/app/assets/run/free_run.svg`로 저장했다. 탭의 21×21 아이콘과 구분하며, 임시 피그마 자산 URL은 소스에 넣지 않았다. 사용된 공통 SVG와 신규 SVG의 파일 존재·크기·호출 위치를 확인했다.

## 실제 데이터에 맞춘 표시

- 최근 기록 조회는 아직 연결 전이므로 최근 카드에는 빈 상태를 표시한다.
- GPS·심박수·케이던스·고도·칼로리가 없으면 `—` 또는 미연결 상태를 표시한다. 피그마의 예시 숫자를 실제 기록처럼 표시하지 않는다.
- 지도와 구간 차트에는 자료가 없는 상태를 표시한다. 피그마의 지도 도식은 시안용이며 실제 GPS 연결 단계에서 기존 `MapView`를 사용한다.
- 결과에는 ‘러닝 완료 · 저장 전’을 표시하고, 앱 종료 시 기록이 사라진다는 안내를 유지한다.
- 코스·고스트 선택, 설정·공유 버튼은 준비 중 안내를 표시한다. 코스 등록과 구간 상세 분석은 실제 기능 연결 전이다.

- 동작 검증: 짧게 누르기, 카운트다운 취소, 정지·재개, 종료 취소·확정, 결과 확인, 전체 화면 탭 숨김과 복원, 경로 이동 후 동일 세션 유지.
- 시간 기준: 120초 세션에서 20초 정지하면 총 120초·달린시간 100초. 정지 중 이동 제외 검증 유지.

화면 캡처는 `FrontEnd/app/build/run-design/`에 생성했다. 필요하면 앱 폴더에서 다음 명령으로 다시 생성한다.

```text
flutter test test/run/free_run_design_test.dart --dart-define=RUN_DESIGN_CAPTURE_DIR=build/run-design
```

캡처의 상단 안전 영역에는 OS 상태바 아이콘을 그리지 않으며, 디버그 실행의 배너가 표시된다. 실기기·GPS·저장·서버 동작은 이번 디자인 검증의 통과 항목이 아니다. 새로운 로컬 자산을 반영하려면 앱을 완전히 다시 실행한다.
