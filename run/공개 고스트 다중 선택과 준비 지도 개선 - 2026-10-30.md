## 공개 후보 API

`GET /api/v1/rankings/courses/{courseId}/ghost-candidates?period=ALL&sort=FASTEST&size=20&cursor=...`

- JWT 필수. `period=ALL|MONTH|WEEK`, `sort=FASTEST|SIMILAR`. 기본 20개·최대 50개. 잘못된 기간·정렬·크기·커서는 기존 공통 400 오류다.
- `ApiResult<CursorSlice<PublicGhostCandidate>>`: `content`와 `nextCursor`. 행은 `runRecordId`, `memberId`, `rank`, `courseElapsedSeconds`, 공개 표시용 `nickname`, `profileImageUrl`, `paceSecondsPerKm`, `completedAt`다. GPS·개인 센서 지표를 읽거나 반환하지 않는다.
- 기존 ranking 소유 쿼리로 같은 코스·기간의 회원별 가장 짧은 대표 기록을 고른다. 기간은 기존 등록 시각·Asia/Seoul 기준이다. 본인·비공개·삭제 기록과 숨김/삭제 코스를 제외한다.
- FASTEST는 기존 순위·동률 안정 순서다. SIMILAR는 요청자의 같은 코스·기간 최고 총 소요시간과 절대 차이가 작은 순이다. 같은 차이는 원래 순서를 유지한다. 비공개 요청자의 자기 최고 기록도 정렬 기준으로 쓸 수 있지만 타인 후보에 넣지 않는다. 내 기록이 없으면 FASTEST와 같다. 이 정렬은 순위·대표 기록·완주 자격을 변경하지 않는다.
- 커서는 기존 랭킹과 같은 오프셋이다. 새로 진입·기간/정렬 변경·새로고침은 첫 페이지부터 받는다. 조회 사이 등록/삭제가 발생하면 중복/누락 가능성이 있어 앱이 기록 ID로 중복을 제거하며, 선택 시 현재 원본을 재검증한다.
- 기존 내부 `RankingApi.getPublicGhostCandidates`의 최대 10개 계약과 B1/B8 자동 첫 후보 선택은 유지한다. 새 전체 목록은 ranking 내부 reader로 제공하며, 선택 재검증은 기존 `findPublicGhostCandidate`로 11위 이후도 동일하게 처리한다. 다른 모듈 스키마 직접 조회는 추가하지 않는다.
- 조회 후보가 재생 품질까지 통과했다는 뜻은 아니다. 선택 후 기존 run 공개 재생 API가 경로 버전·시간·30초/5% 품질을 확인한다. 실패한 상대를 다른 기록으로 자동 교체하지 않는다.

## 앱 동작

- C2에 공개 후보 최대 3명을 표시하고 `다른 러너 전체 보기`로 C10을 연다. C10은 기간, 빠른 순/나와 비슷한 기록, 추가 페이지, 선택 표시, 빈 목록·오류·재시도를 제공한다.
- C9 내 기록 전체와 C10 다른 러너 탭을 양방향으로 연결한다. 공개 선택은 정확한 원본 ID와 선택 기간을 기존 공개 준비 화면으로 전달한다. 선택만으로 측정·시작 승인·도전 수를 발생시키지 않는다.
- 후보 요청에 기존 인증 인터셉터의 `runOwner`를 전달한다. 계정·코스·러닝 상태 변경은 부모 화면이 선택 화면을 닫고, 폐기된 요청·변경 전 필터의 늦은 응답은 무시한다.
- 추가 페이지 실패는 기존 목록·선택·커서를 유지한다. 기간·정렬 변경은 이전 선택을 지운다. 공개 목록 실패가 본인 기록 선택을 막지 않는다.
- C9-F1은 출발점을 기준으로 한 고정 확대 대신 준비된 모든 경로 조각을 `MapController.fitPoints`로 맞춘다. 조각 사이 선은 만들지 않는다. 지도 준비 직후, 경로 변경, 화면 크기 변경 시 다시 맞추고 같은 경로의 일반 재빌드·사용자 지도 조작에는 카메라를 되돌리지 않는다.
- C8은 코스 카드 선택 후 목록 아래에 높이 200의 전체 경로 미리보기를 표시한다. 목록 썸네일 대신 기존 코스 상세 API의 전체 경로를 쓰며, 코스 변경 시 이전 지도와 분리한다. 로딩·조회 실패·다시 불러오기를 제공하고 지도 실패가 코스 선택 전체를 막지 않는다.
- 두 미리보기 모두 기존 지도 래퍼·네이버 지도 SDK를 사용한다. C8에는 출발/도착 표지를 표시하고, 높이 120의 C9-F1에서는 표지가 경로를 가리지 않도록 선 위주로 표시한다. 앱에는 실제 지도가 표시되며, 자동 위젯 테스트 이미지는 개발용 지도 배경을 사용한다.

## 적용 순서와 범위

새 후보 목록 API를 포함한 서버를 먼저 배포하고 앱을 재빌드·설치한다. 이전 서버의 404는 공개 목록 오류/재시도로 표시되며 본인 기록과 기존 랭킹 경로는 유지된다. 임의의 테스트 러너나 합성 기록을 운영 데이터에 추가하지 않는다.
