# 러닝 파트 분담

2026-10-12 · 1번 김효성, 2번 문석용

## 역할

| | 1번 김효성 | 2번 문석용 |
| --- | --- | --- |
| 기능 | F5 자유 러닝 + F9 고스트 | F6 코스 러닝 + 구간 분석 |
| 주인 | 측정 엔진·기기 저장·복구, 업로드·처리 상태, 기록 목록·조회·삭제, 고스트 후보·재생·승패 | 서버 코스 판정 엔진, 앱 코스 안내(이탈·도착), 코스 시작·구간 종료·현재 러너 수, `RunApi` 리뷰 자격, 음성(`AudioGuide`), 분석, 코스 등록용 경로 |
| 화면 | C5·H4·C4 자유·일시정지·D1-2 / C1·C2·C9·C10·H5·C4 고스트·D2 | C6·C8·H1·C4 코스·C4-3·D1·D1-1 / D3·D5·D6 |

- 공통 화면 틀(C4, 카운트다운, 일시정지, 결과 공통부)은 먼저 만드는 사람이 공통 위젯으로 만들고 나중 사람은 그 위에 모드 요소만 얹는다. 순서상 1번이 먼저다.
- 미배정: 오류 화면(GPS 신호 약함, GPS 끊김, 러닝 기록 없음, 경로 이탈 기본 화면).
- run 아님: D4 코스 등록 화면(F7 서현석, run은 경로 API·진입 버튼만), I1 내 러닝 기록 화면(MY, run은 API·진입점만), 위치 권한·네트워크 오류·주변 코스 없음(공통·홈).

단계는 기간이 아니라 완료 기준으로 넘어간다. 실기기(Android·iPhone) 검증은 초반부터 한다.

## 공통 규칙

- 러닝 중 원본은 기기에 저장, 세션 종료 후 업로드. 자유 러닝만 오프라인 시작.
- 앱이 도착 안내·자유 러닝 전환, 최종 완주·리뷰 자격·고스트 결과는 서버. 통신 90초 전환 없음(정책 4.2).
- 이탈 30초 자동 전환 없음. 코스 도전 중단은 일시정지 → 종료 → 코스만 종료. 구간 종료 시 입력 순번·사유 기록(정책 4.4).
- 세션 UUID는 기기 생성, GPS·조작 이벤트는 세션 단일 순번, 시간은 ms·UTC, 거리는 m, 미수집 센서는 `null`·화면 `—`.
- 기본값: 정수 초 `floor(ms/1000)`, `registeredAt`은 검증 후 최초 등록 시각, 방치 세션 제외 3시간. 정수 초·`registeredAt`은 ranking 담당과 계약 PR에서 확정.
- 패키지: `geolocator`, `sqflite`, `flutter_tts` (래퍼 뒤에 둠).
- PR은 계약 먼저, 구현은 작게. 서로 리뷰. 스텁 통과와 실제 연동 통과는 구분해서 기록.

## 로컬 실행 주의

- 코스 스텁: `--app.stub.course=true` (기본은 실제 `CourseApi`)
- 앱 없이 로그인: `--app.member.social.fake=true`

## 완료 기준

실제 Android·iPhone에서 자유·코스·고스트 러닝을 하고 기기 저장 → 실패 복구 → 서버 판정 → 다른 모듈 반영 → 재조회가 통과한다. 기록 유실·중복 등록·잘못된 완주·잘못된 승패가 없어야 한다.
