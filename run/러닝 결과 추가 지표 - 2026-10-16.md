# 러닝 결과 추가 지표 · 2026-10-16

사용자가 승인한 계산 기준으로 상승 고도, 최고 구간, 최고 페이스를 실제 원본에서 계산하고 자유 러닝 결과/기록에 표시한다.

| 지표 | 기준 |
| --- | --- |
| 상승 고도 | 확인된 이동의 GPS 고도, 5초 중앙값, 10m 상승/반전 확인, 오르막 합계 |
| 최고 구간 | GPS 공백 없는 완성된 1km 자동 랩, 이동시간 페이스, 동률이면 앞 랩 |
| 최고 페이스 | 확인된 연속 30초 이동 거리, 경계 보간, 전체 창 최솟값 |

분석용 고도 정확도 20m·수직 변화 3m/s 등 초기 품질 기준과 누락/부분 측정 처리의 세부 규칙은 정책 문서의 RESULT_V1 절을 따른다. 원본 수집을 제한하지 않으며 기존 거리·시간·랩·등록 시각·랭킹은 변경하지 않는다.

앱/서버 공통 fixture 17개를 사용한다. SQLite 종료→닫기→재조회, summary/detail, 동기화, stats 없는 이전 서버 결과의 기기 원본 보완을 검증한다. 서버 업로드→저장→목록→상세→과거 결과 보완과 계정 경계를 검증한다. 실제 Pretendard 글꼴의 320px·402px 결과 화면도 렌더링한다.

검증 실행 로그 및 화면은 작업 보관 폴더 `run/result-metrics-2026-10-16`에 둔다. 서버 배포와 실제 휴대폰 주행은 이 구현 검증에 포함하지 않는다. 서버→앱 순서로 배포하며 기존 고도가 없는 기록은 임의 고도를 생성하지 않는다.

검증 결과: 앱 전체 **236개 통과**, 서버 러닝 관련 **51개 통과**(실패·오류 0), 러닝 소스·테스트 정적 분석 지적 없음. 공통 시나리오 **17개**의 앱·서버 일치와 원래 거리/시간/랩 불변을 확인했다. 실제 글꼴의 320px·402px 렌더링 확인을 완료했다.
