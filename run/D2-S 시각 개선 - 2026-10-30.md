# D2-S 시각 개선 · 2026-10-30

사용자 요청: 글 위주의 대결 구간 상세를 실제 기록을 시각적으로 비교하는 화면으로 개선한다.

## 화면

- 코스·거리와 레이스 제목, 본인 최고 1km 구간과 상대보다 구간 시간이 짧은 구간 수를 요약한다. 확인 불가능한 구간은 앞선 구간 수의 분모에서도 제외한다.
- 페이스 탭: 나의 막대와 고스트 점선을 같은 축에 표시한다. 높을수록 빠르며, 선택 구간의 바탕과 막대를 강조한다. 마지막 짧은 구간도 1km당 페이스로 환산해 다른 구간과 비교한다. 축은 실제 자료에 따라 조정한다.
- 누적 격차 탭: 기존 누적 시간 차이 그래프를 유지한다. 확인할 수 없는 값은 선을 연결하지 않는다.
- 막대 또는 구간 카드 선택 시 하나의 카드만 펼친다. 구간 소요시간, 두 비교 막대, 구간 차이와 누적 차이, 부분 구간 페이스와 자료 부족 사유를 표시한다. 작은 화면에서도 값이 겹치지 않게 줄바꿈한다.
- 선택 바탕·카드 펼침·탭 전환에 짧은 전환 효과를 넣고 기기의 애니메이션 줄이기를 따른다. 그래프 선택 영역은 접근성 설명과 선택 상태를 제공한다.
- 결과로/전체 러닝 분석은 하단 버튼으로 유지한다. 기존 결과 비교 계약의 계산·판정·공개 범위는 유지한다.

## 피그마

- 기존 D2-S `2555:8639`를 수정해 진입 연결을 유지했다.
- 누적 격차 상태 D2-S2 `2574:8659`를 추가하고 두 탭을 연결했다. 결과/전체 분석 연결도 유지했다.
- 화면의 펼친 카드는 4구간 대표 상태다. 앱은 모든 막대·구간 선택을 지원한다.
- 기존 로컬 Summary tile, Bottom bar, Button, App bar와 색·간격 토큰을 재사용했다. 두 상태를 화면으로 확인했다.
- 피그마 상단 공유 아이콘은 기존 디자인에 남아 있으며 공유 기능 구현은 이번 시각 개선 범위에 포함하지 않았다.

- `ghost_segment_comparison_screen.dart`: D2-S 시각화와 상호작용.
- `ghost_gap_chart.dart`: 기존 D2 누적 그래프를 공용 파일로 이동했다. D2 기존 계산·표시는 유지했다.
- 새 시각 검증 5개: 320/402px 화면·막대 선택·탭 전환, 마지막 0.2km의 시간/페이스 구분, GPS 자료 없음과 분모, 320px 큰 글씨 1.6배.
- 앱 전체 **796 tests passed**. 기존 결과·재도전·일반 분석 관련 테스트 포함.
