# 자유 러닝 기본 기능 1~4 구현

실제 프로젝트: `C:/Users/USER/IdeaProjects/WADADAK`. 일반 와다닥 앱 `1.0.3+4`, 원격 API `https://api.leedohyunn8n.shop/`를 사용한다.

## 적용 기능

1. 확인된 거리마다 1km 자동 랩 생성. GPS 이동 구간 내 경계를 보간하고 일시정지·GPS 공백은 직선으로 잇지 않는다. 기본 랩 시간·페이스는 이동시간 기준, 정지를 포함한 랩 시간도 보존한다. 마지막 부분 랩은 실제 거리로 표시한다.
2. MY와 러닝 준비 화면에서 전체 기록 목록·상세·삭제. 기기/서버 기록을 ID로 합치고 이전 페이지·재시도·동기화 상태를 지원한다. 상세에는 과거 경로·두 시간 기준·랩·케이던스를 표시한다. 삭제 확인 후 원본을 기기에서 지우고 계정별 삭제 이력을 먼저 저장한다. 서버는 같은 ID의 늦은 업로드를 거부한다.
3. Android 한국어 TTS 음성 안내. 기본 ON·거리 1km, 거리 1/2/5km 또는 달린시간 5/10/15분 중 선택한다. 일시정지·종료·계정 변경 시 중단하고 지난 안내는 재생하지 않는다. 설정·미리보기·재생 실패 안내를 제공한다. 러닝이 없는 대기 상태의 타이머는 수동 음성 미리보기를 중단하지 않는다.
4. Android 실제 걸음 감지 센서 우선, 누적 걸음 센서 대체. 수동 일시정지 때 센서를 중단하고 재개 시 기준을 초기화한다. 걸음 수와 측정 구간의 단조 시각을 저장해 평균을 복구·서버 재계산한다. 현재 케이던스는 최근 10초, 평균은 센서 측정 시간 기준이다. 미지원·미수신은 —, 일부 누락은 결과에 표시한다. 러닝 시작 때 위치·신체 활동 권한을 확인·요청한다.

코스 러닝·고스트 대결은 이번 범위에 포함하지 않는다. 기존 평균/현재 페이스의 3초 표시 정책, 이동시간/총 소요시간 구분, 중단 복구 규칙은 유지한다.

## 검증

- 앱 `dart analyze`: 오류 없음. 전체 Flutter 테스트 **132개 통과**.
- 서버 전체 Gradle 테스트 **147개 통과**, 모듈 분리 검증 포함. 러닝 모듈 검증은 17개.
- 디자인 시스템 예제 정적 검사·카탈로그 테스트 1개 통과.
- 공통 fixture `run/fixtures/free_features_v3.json`: 앱·서버 거리 2550m, 전체 580000ms, 달린/이동 시간 541000ms, 랩 1000/1000/550m, 평균 케이던스 180spm 일치. 일시정지 이동·GPS 공백·센서 입력을 함께 포함한다.
- SQLite v1→v2 업그레이드 보존, 계정별 설정·삭제 큐, 오프라인 삭제 후 재시작·업로드 응답·화면 캐시 조회 지연 중 삭제, 서버 처리·삭제 경쟁과 반복 요청을 검증했다.
- 320px/402px에서 실제 랩·케이던스·과거 경로 결과 화면 및 기록 페이지 이동·삭제 확인·설정 저장을 검증했다.
- 일반 앱 APK 빌드 완료. Galaxy S21에 같은 서명으로 업데이트 설치했다. 기존 내부 종료 세션 8개(개인 목록에 표시되는 양수 거리 기록 5개)가 보존되고 SQLite 버전이 1→2로 변경되었다.
- Galaxy S21의 걸음 감지/누적 걸음 센서 지원 확인, MY와 설정 화면 진입 확인. 한국어 음성 미리보기의 시스템 오디오 시작→정상 종료(약 4.01초)를 확인했다. 대기 타이머에 의한 1초 중단은 발생하지 않았다. 실제 야외 러닝으로 케이던스 정확도·장시간 화면 꺼짐을 검증한 것은 아니며, 회복·정지·누락·시각 처리는 자동 테스트로 확인했다.

## 서버 적용

실제 원격 서버에는 이번 러닝 API 변경을 아직 배포하지 않았다. 기기 기록은 바로 조회 가능하며 서버 동기화·서버 삭제는 백엔드 배포 후 사용한다. 기존 업로드가 동기화 확인 필요로 표시되면 MY에서 동기화를 누른다. 마이그레이션 `V20261014_1600__run_deletions.sql`을 포함해 run 모듈 전체를 배포한다.
