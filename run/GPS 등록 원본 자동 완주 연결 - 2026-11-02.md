# GPS 등록 원본 자동 완주 연결 · 2026-11-02

상태: 정책 공통 3-1에 따른 로컬 구현·검증. 원본 코드 기준 `739c9e6`. 담당자 검토·운영 배포·기기 설치·기존 운영 자료 보완은 별도다. 기존 확정 정책이나 담당자 승인 상태를 새로 확정하지 않는다.

## 사용자 흐름과 정책 대조

자유 러닝 또는 내 자유 기록 고스트의 전체 개인 기록으로 GPS 코스를 등록하면, 등록 성공과 별도로 원본을 그 코스의 첫 완주 성과로 연결한다. 추가 코스 주행이나 출발·도착·95% 재완주를 요구하지 않는다.

| 정책 | 구현 |
| --- | --- |
| 원본 보존 | 원래 결과의 `course`, GPS·거리·시간·페이스·종료 사유·등록 시각·고스트 결과를 수정하지 않는다. 새 개인 기록이나 코스 시도를 만들지 않는다. |

| 중복 집계 방지 | 코스 완주 수·평균 페이스·최근 완주·랭킹·실제 리뷰 자격만 연결한다. 개인 거리·횟수·도전 수·현재 러너 수·유지 기간을 늘리지 않는다. |

## 이벤트와 모듈 경계

기존 `CourseCreatedEvent`, `RunSessionEndedEvent`, `RunRecordDeletedEvent`의 필드·의미를 바꾸거나 연결용으로 재발행하지 않는다. course→run 동기 호출, 다른 모듈 내부 import·스키마 조회·FK를 추가하지 않는다.

1. **course → `GpsCourseRegisteredEvent`**: eventId·occurredAt·courseId·creatorId·sourceRunRecordId·courseName·route·distanceMeters·courseVersion·status·sourceSegments. 최종 경로와 등록에 실제 사용한 정제 전 조각을 함께 전달한다. 기존 등록 알림과 별도인 버전된 DTO이며, 등록·불변 발행 스냅샷·Modulith 아웃박스가 같은 트랜잭션이다.
2. **run → `GpsSourceLinkedEvent`**: 원본 ID가 안정적인 연결 키다. 회원·코스, 전체 세션 정수 초·코스 거리, 실제 인정 거리·진행도·리뷰 자격, 원본 시작/종료/완주/최초 등록 시각과 `GPS_SOURCE_COMPLETION_V1`을 전달한다. 연결 저장과 발행이 같은 트랜잭션이다.
3. **run → `GpsSourceUnlinkedEvent`**: 별도 이벤트 ID·시각·원래 연결 성과·해제 사유를 전달한다. 수신자는 해제가 생성보다 먼저 와도 삭제 표시를 남긴다.

course는 기존 `course_completions`와 통계에 반영하며 별도 연결 수신 장부로 적용/해제 상태를 관리한다. 이벤트 ID 처리 기록과 원본 유일성을 함께 사용한다. ranking은 코스 엔트리만 삽입하고 누적 거리 표를 만들거나 수정하지 않는다. review는 자기 모듈의 기존 기록 복사/삭제 처리를 재사용하며 새로운 러닝 종료 이벤트를 발행하지 않는다.

## 원본 검증과 상태

run은 자기 세션·처리 완료 결과·원본 입력·삭제/탈퇴 표시와 이벤트 자료만 사용한다. 서버 재계산 거리·전체 경과시간·종료 시각이 저장 결과와 일치하는지 확인하고, 재생성한 원본 경로 조각이 등록 자료와 일치하는지 검증한다. 일반 코스 러닝 원본은 이 연결 대상이 아니다.

`run.gps_source_links`의 상태는 `PENDING / LINKED / REJECTED / REMOVED`다. 원본 업로드 처리 중에는 PENDING으로 두고 `GpsSourceLinkWorker`가 재시도한다. 일시적 DB/트랜잭션 오류는 롤백되어 아웃박스/대기 작업으로 재시도한다.

영구 제한 사유는 `MEMBER_WITHDRAWN`, `SOURCE_DELETED`, `COURSE_UNAVAILABLE`, `SOURCE_NOT_FOUND`, `SOURCE_OWNER_MISMATCH`, `SOURCE_PROCESSING_FAILED`, `SOURCE_IS_COURSE_RUN`, `SOURCE_REGISTRATION_INVALID`, `SOURCE_INPUTS_UNAVAILABLE`, `SOURCE_RESULT_MISMATCH`, `SOURCE_ROUTE_MISMATCH`다. 이 경우 원본을 변경하거나 추정하여 맞추지 않는다. 거절/삭제 연결의 경로 스냅샷은 비운다.

본인 전용 `GET /api/v1/runs/records/{id}/gps-course-link`는 `ApiResult<{courseId,status,failure,linkedAt}>`를 반환한다. 이벤트가 아직 도착하지 않았으면 NOT_RECEIVED, 다른 회원·없는/삭제된 기록은 기존 RUN-002/404다.

D4는 코스 등록 성공 후 이 상태를 한 번 확인하고 기존 성공 팝업 안에서 연결 완료/대기/실패를 구분한다. 상태 확인은 최대 3초이며 실패해도 이미 성공한 코스 등록을 다시 보내지 않는다. 아직 반영되지 않은 원본의 완료를 먼저 표시하지 않는다.

## 고스트·PB·호환

- 자동 완주 원본의 재생은 `GHOST_PLAYBACK_GPS_SOURCE_V1`이다. 기존 코스 완주의 최초 완주 재판정 일치 조건을 적용하지 않고, 연결 스냅샷으로 원본 전체 세션 시간축의 파생 위치·정지·공백을 만든다.
- 자유 기록 고스트의 SEGMENT_END는 전체 세션 종료가 아니므로, 파생 계산에서만 제외하고 순번을 다시 부여한다. 원본 입력은 바꾸지 않는다. 수동 정지·GPS 공백은 유지한다.
- 10초 초과 연결 금지·원본 공백 30초/5%·위치 재현 적합성을 유지한다. 불확실한 위치/공백은 채우지 않으며 재생 불가가 자동 완주·랭킹 성과를 취소하지 않는다.
- 내 후보/공개 후보·선택 준비·실제 시작·기기 원장·SQLite 재실행·60초 복구·동일 상대 재도전이 이 재생 버전을 유지한다. 승인 뒤 원본이 삭제되어도 저장한 상대·경로·시간·버전은 유지한다.
- 코스 PB 기준에는 시작 전에 연결 완료된 동일 코스·경로·거리의 원본 성과를 포함한다. 연결 전 과거 대결의 PB를 소급 바꾸지 않는다.
- 새로 달리는 러너의 일반 코스 완주 판정·최초 완주 비교 시간은 기존 규칙을 유지한다. 자동 원본의 전체 세션 시간 예외를 새 러너에게 전파하지 않는다.
- 기존 코스/자유 고스트의 V1/V2 형식과 기존 기기 스키마는 유지한다. 새 자동 원본의 선택에는 새 앱이 필요하며 구버전 앱에 새 재생 버전을 V1으로 가장하여 전달하지 않는다.
