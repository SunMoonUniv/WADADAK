# 페이스 측정·표시 구현

실제 실행 프로젝트: `C:/Users/USER/IdeaProjects/WADADAK`.
정책과 공통 기록 엔진·서버 소스는 작업 복사본에도 반영했다.

## 동작

- 자유 러닝 평균 페이스는 이동시간/거리이며, 랭킹용 총 소요시간과 총 시간 기준 페이스는 별도로 보존한다.
- 최근 정상 이동 10초의 시간/거리로 현재 페이스를 계산한다. 표시값만 5초/km 단위로 반올림한다.
- 페이스 표시값은 3초 구간마다 갱신한다. 시간·GPS·원본 저장은 계속 진행하고 상태 전환·신호 변화·최종 결과는 즉시 반영한다.
- 초기 누적 거리가 25m에 도달하기 전에는 평균 페이스를 `—`로 표시한다. 현재 페이스는 최소 3초·3m의 확인된 이동이 필요하다.
- 최소 3개 연속 표본으로 실제 이동을 확인한다. GPS 속도와 속도 오차를 함께 사용하며, 속도 정보가 불확실하면 정확도·연속 변위를 사용한다.
- 5초 이상의 확인된 정지는 이동시간에서 제외한다. 물리적 정지는 수동 정지 화면으로 강제 전환하지 않는다.
- 정확도 부족·GPS 공백·위치 튐·수동 정지/재개 전후는 거리와 현재 페이스 계산에서 연결하지 않는다. GPS 공백 자체로 이동시간을 차감하지 않는다.
- 신규 START 입력의 `reason=PACE_V2`로 계산 버전을 보존한다. 이전 기록의 거리에는 새 필터를 소급 적용하지 않는다. DB 삭제나 기존 기록 삭제가 필요하지 않다.
- 지도는 확인된 이동 경로를 표시하고 원본 위치는 기기에 보존한다.
- 결과 화면에서 이동시간·달린시간·총 소요시간 및 이동시간 평균 페이스·총 시간 기준 페이스를 구분한다.

## 검증

- 실제 앱 전체 테스트 **106개 통과**, Dart 정적 검사 문제 없음.
- 320px·402px 화면에서 페이스 표시와 종료 조작 확인.
- 실제 서버 테스트 **13개 통과**: 계산 7개, 인증·입력·저장·재전송 등의 통합 검증 6개.
- 작업 복사본 러닝 테스트 33개 통과.
- 앱·서버 공통 `free_motion_v2.json`: 거리 30m, 이동시간 10초, 총 소요시간 30초. 기본 평균 페이스 약 5분 33초/km, 총 시간 기준 페이스 16분 40초/km.
- 정지 GPS 잡음, 신뢰 가능한 정지 속도의 GPS 드리프트, 저속 이동·정지 후 저속 재출발, 회전, 수동 정지·재개, GPS 공백·불량·위치 튐, SQLite 재생, 저장 실패, 3초 갱신 및 현재 페이스 즉시 무효화 검증.

## 설치·배포 범위

- 일반 Android 앱 `com.wadadak.app`, **1.0.2+3** 빌드 및 Galaxy S21 업데이트 설치 완료.
- 실제 프로젝트의 기존 팀 디버그 키로 서명했다. 기존 로그인·러닝 기록·위치 권한을 유지했다.
- `API_BASE_URL=https://api.leedohyunn8n.shop/`를 포함했다.
- 서버 소스와 마이그레이션은 실제 프로젝트에도 추가했으며 로컬 테스트를 통과했다. 다른 컴퓨터의 원격 서버에는 배포하지 않았다.
- 임계값은 첫 구현값이다. 통제된 실외 주행에서 거리 오차·정지 판정·속도 변화의 반응을 추가 검증해야 한다.

## 실기기 확인

- 일반 앱 1.0.2에서 평균 페이스·현재 페이스·이동시간 표시 확인.
- 실제 GPS 원본 92개 수집·기기 저장 확인. 최신 위치 정확도 약 28.7m로 신호가 약한 상태였다.
- 확인된 정지 시간을 제외해 일시정지 시 이동시간 약 33초, 총 소요시간 약 78초로 구분되는 표시를 확인했다.
- 확인되지 않은 이동은 거리로 더하지 않았고 거리 0.00km·평균/현재 페이스 `—`, 정확도 부족 안내를 표시했다.
- 확인용 세션은 USER 종료, 총 소요 124,769ms로 정상 마감했다. 거리 0이므로 개인 기록·업로드 대상으로 만들지 않았다.
- 종료 후 위치 foreground 서비스가 해제됐다. 기존 4개 저장 세션은 그대로 유지했다.
- 이번 실기기 확인은 설치·표시·수집·품질 안내·종료를 검증한다. 통제된 실외 거리 정확도나 실제 이동 중 3초 표시를 검증한 것으로 해석하지 않는다. 계산·3초 갱신·정지 중 평균 유지 동작은 자동 테스트로 검증했다.
