## 계약과 기존 데이터

- 사용자가 확인한 정책 버전은 `2026-10-14`이며, 계산 버전 `PACE_V2`와 별도로 관리한다. 과거 결과에 없는 버전을 새 버전으로 소급 표기하지 않는다.
- 기존 원본·기기 DB v2·정책별 계산 결과와 ID를 유지한다. 기존 서버 결과의 summary는 이미 저장된 결과에서 만든다. 미발행 등록 이벤트의 발행 시에도 결과·registeredAt을 재계산하지 않는다.
- 기록 목록 응답은 팀 계약인 `content`·`nextCursor`로 변경했다. 새 앱과 서버를 함께 적용해야 한다.
- 새 마이그레이션은 `run/V20261014_2000__run_policy_alignment.sql`, `ranking/V20261014_2001__ranking_run_distance_copies.sql`이다. 이미 머지된 두 run 마이그레이션은 보존했다.
- ranking 복사본은 F12 집계 원천이다. 기존 랭킹 API/화면은 여전히 스텁이며, 이 수정으로 실제 거리 랭킹·자정 스냅샷까지 구현했다고 보지 않는다. 코스/고스트 기능도 이번 수정 범위에 추가하지 않았다.
