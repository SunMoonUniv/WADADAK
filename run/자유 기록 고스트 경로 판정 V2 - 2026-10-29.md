# 자유 기록 고스트 경로 판정 V2 — 2026-10-29

사용자가 승인한 범위: 잘못된 과거 구간 대응을 수정하며, 새로 시작하는 자유 기록 고스트의 원본과 러너에 같은 방식을 적용한다. 정책 9.6 P1~P4의 완주·비교 시간·품질·원본 보존 조건은 변경하지 않는다. 일반 코스·내/공개 코스 고스트 및 기존 FREE_V1 대결은 기존 추적기를 유지한다.

## 버전 고정과 배포

- 새 앱은 자유 원본 준비 GET에 `playbackVersion=GHOST_PLAYBACK_FREE_V2`를 명시한다. 응답이 다른 버전이면 준비 완료로 넘기지 않는다.
- 서버 GET에서 인자가 없으면 FREE_V1이다. 기존 앱의 새 준비도 기존 방식으로 동작하며, 무조건 V2로 올리지 않는다. 알 수 없는 버전은 거절한다.
- 시작 요청은 선택 준비에서 받은 버전과 해시를 그대로 보낸다. 승인된 playback.version이 해당 대결의 경로 판정 방식이다. 원본 재생과 서버 러너의 완주/승패 판정이 이 버전을 함께 사용한다.
- 이미 승인된 같은 요청의 재시도는 저장 승인을 반환한다. 다른 버전으로 바꾸는 재시도는 충돌이다. 원본 삭제 뒤에도 승인·상대·버전은 바뀌지 않는다.
- 앱은 시작 원장 JSON에 playbackVersion을 저장한다. 기존 GHOST_DEVICE_V1에 이 필드가 없으면 FREE_V1/코스 V1으로 복원한다. 새 V2 대결의 재시도·SQLite 재실행·60초 복구는 V2를 보존한다. DB 스키마 변경은 없다.
- 승인/결과 봉투는 GHOST_START_FREE_V1/GHOST_RESULT_FREE_V1을 유지한다. 봉투 형식과 추적기 버전은 별개다. PACE 버전·기존 정책 버전·원래 저장 거리·시간은 변경하지 않는다.
- 서버를 먼저 배포하고 새 앱을 적용한다. V2 대결이 시작된 뒤에는 해당 버전의 업로드·결과 판정 지원을 유지해야 한다. 신규 V2 시작을 중단하더라도 이미 승인된 V2를 V1으로 재판정하지 않는다. 구버전 앱으로 새 V2 저장 자료를 여는 것은 지원하지 않으며 버전 검증을 우회하지 않는다.

## V2의 경로 대응

별도 FreeGhostTracker를 CourseJudge.freeGhostV2()에서만 사용한다. 기존 CourseJudge 기본 생성자와 CourseTracker는 V1 동작을 유지한다. Flutter도 CourseTracker의 명시적 freeGhostV2 선택만 새 추적기로 연결한다.

1. 신뢰 가능한 GPS에서 경로 20m 이내 투영 후보를 구한다. 경로 밖·불량 GPS·일시정지·재개·GAP·10초 초과 간격에서 연결과 미확정 이력을 끊는다. 원본 좌표 속도 12m/s 초과인 튐 표본 자체도 유효 위치로 내보내지 않는다.
2. 후보의 좌표 거리, 실제 이동과 경로상 이동의 차이, 구간 방향과 실제 이동 방향, 진행 순서를 함께 평가한다. 동일 좌표의 왕복 구간도 전후 이력과 방향으로 구분한다. 이전 위치에서 덜 움직이는 후보만 우선하지 않는다.
3. 서로 떨어진 후보가 비슷하게 설명되면 위치를 미확정으로 두고 다음 GPS의 증거를 함께 검토한다. 해소되면 보류했던 위치와 연결을 소급 확정한다. 공백·일시정지·불량 신호를 넘어 소급 연결하지 않는다. 끝까지 해소되지 않으면 확인 불가로 남긴다.
4. 후보가 이전 경로 위치에서 도달 가능한 범위에 없으면 새 위치를 찾되 그 사이를 주행 거리로 인정하지 않는다. 과거 연결을 임의로 복원하지 않는다.
5. 후보 이력은 상한 8개로 제한한다. 이를 넘으면 후보를 버려 가짜 확신을 만들지 않고 미확정 상태로 다시 확보한다. 경로상의 20m 이내 인접 투영 후보는 같은 주변 구간 후보로 묶는다.

첫 V2의 구현 점수는 공간 오차 제곱 + 이동 길이 오차 제곱×0.25 + 역행 시 실제 이동 제곱×0.25 + 방향 오차 항이다. 후보 비용 차이 9를 초과하면 구분 근거로 사용한다. 이 값은 새로운 사용자 자격 기준이 아니라 버전으로 고정한 구현값이다. 의미가 달라지는 변경은 기존 승인된 V2를 재해석하지 않도록 새 추적기 버전으로 다룬다. Java와 Dart는 같은 공통 시험 자료의 모든 위치·연결 값을 확인한다.

## 유지되는 정책과 기능 경계

- 자유 원본 최소 1,000m는 서버 저장 거리로 비교한다. 반올림·합산·공백 연결로 자격을 만들지 않는다.
- 원본과 러너 모두 동일 CourseJudge의 출발·방향/순서·끝 도달·95% 인정 거리 판정 및 최초 완주 시각을 사용한다. 원본을 자동 100% 인정하지 않는다.
- 원본의 종료 버튼 시각까지 재생하는 대신 같은 완주 조건을 처음 충족한 원본 경과 ms까지를 비교 구간으로 한다. 시작 후 대기·일시정지를 포함하며, 기존 정수 초 승패와 미완주 종료 경계는 유지한다.
- 수동 정지를 제외한 연속 공백 30,000ms·누적 5% 이하의 두 조건을 유지한다. 10,000ms 초과 연결 금지는 별개다. 정상 GPS로 확인되는 제자리 정지는 공백으로 취급하지 않는다.
- 원래 자유 기록의 거리·이동시간·페이스·랩·고도·종료 사유를 덮어쓰지 않는다. 조회/준비 때문에 원본을 다시 저장하거나 과거 최종 승패를 바꾸지 않는다.
- 일반 코스·기존 내/공개 고스트의 기본 판정, 코스 도전/완주/랭킹/리뷰/유지 기간 이벤트는 변경하지 않는다. 새 자유 대결의 외부 Result.course는 null을 유지한다.
- 앱의 새 자유 대결 진행도·격차·끝 도달 안내와 복구 후 추적도 승인된 버전으로 동작한다. 최종 완주/승패는 서버가 판정한다.
