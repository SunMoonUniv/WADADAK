# GPS 정지 흔들림 보정과 고스트 일치

기준일: 2026-11-02 · Asia/Seoul

## 변경

새로 시작하는 러닝에 `PACE_V4`를 기록한다. 기기에 저장·업로드하는 GPS 원본, 순번, 측정 시각, 센서 값은 보존한다. 계산용 좌표에만 앱·서버가 동일한 `GpsPathFilter`를 적용한다. PACE_V1/V2/V3와 버전 없는 기존 기록은 기존 계산을 유지한다. 이전에 저장된 결과·승패·승인 스냅샷을 재계산하거나 오늘의 실기기 기록을 자동 복구하지 않는다.

- 위치 정확도 15m 이내이고 신뢰 가능한 속도(속도 정확도 0 초과·0.5m/s 이하)가 있는 구간만 보정한다. 근거가 없는 표본은 원래 좌표로 즉시 전달한다.
- 2초 이상에 걸친 연속 3개 표본이 0.2m/s 이하이고 반경 3~6m 안에 있으면 정지 위치를 유지한다. 이동 속도가 확인되거나 반경 밖으로 나가면 해제한다.
- 이동 중 완만한 작은 흔들림은 인접 3점으로 중간 점을 최대 1m만 다듬는다. 방향이 60도 넘게 바뀌는 코너는 이 처리로 누르지 않는다.
- 6m 이내의 작은 왕복 튐도 수신 속도와 모순되고, 앞뒤 직접 이동은 속도와 맞는 경우에만 제거한다. 실제 회전·유턴은 보존한다.
- 보정에 필요한 GPS 한 점을 다음 점까지 보류한다. 실시간 경로·거리 표시에는 보통 한 표본 정도 지연이 추가된다. 정지·종료 시 남은 표본을 반영한다. 센서 이벤트의 순서는 보존하며 코스 구간 종료는 전체 세션 측정의 공백으로 바꾸지 않는다.
- 실제 GAP, 수신 간격 10초 초과, 나쁜 GPS, 원본 좌표의 12m/s 초과 연결을 보정으로 숨기지 않는다. 원본의 두 끝을 유지하고 그 경계를 넘겨 이어 붙이지 않는다.

## 연결 범위

앱/서버의 이동 거리·페이스·경로, 서버 코스 판정, 앱 실시간 코스/자유 고스트 위치 추적, 고스트 재생 위치·정지 위치·공백 판정이 같은 계산용 좌표를 사용한다. GPS 코스 등록에 전달하는 경로도 기존 `FreeRunCalculator.samples` 경로를 통해 보정된 자료를 사용한다.

고스트의 연속 공백 30초·전체 공백 5%, 자유 기록 최소 1km, 출발·끝·95% 경로 재현, 실제 총 소요시간, 정수 초 승패 기준은 변경하지 않는다. 휴대폰의 나침반/기기 방향을 경로 방향으로 추가 사용하지 않는다.

## 검증과 적용

공유 합성 자료 `run/fixtures/gps_path_v4.json`은 정지·센서 혼합·작은 튐·완만한 흔들림·직각 회전·유턴·느린 걷기·불량 정확도·수신 공백·일시정지·기존 버전·짧은 기록을 포함한다. 1.26km 경로에서 60초씩 두 번 정지한 원본의 고스트 적합성과 실제 40초 공백의 거절을 별도로 검증한다. 실제 사용자의 위치 자료는 검증에 사용하지 않았다.

서버/앱 수치 일치 검사와 전체 실행 결과는 작업 보고서에 기록한다. 새 서버를 먼저 적용한 뒤 새 앱을 설치해야 한다. 구버전 서버의 자유 고스트 준비 API는 PACE_V4를 지원하지 않는다. DB 마이그레이션은 없다. 운영 배포·휴대폰 설치·야외 재검증은 별도다.
