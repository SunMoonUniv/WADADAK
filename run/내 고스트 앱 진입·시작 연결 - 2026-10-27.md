# 내 고스트 앱 진입·시작 연결 · 2026-10-27

## 구현 범위

달리기 탭의 ‘고스트 대결’을 내 완주 기록 선택과 기존 출발 준비/서버 시작 승인/기기 저장 흐름에 연결했다. 본인 기록 선택은 정책 공통 6의 개인 기록 진입점이다. 코스 상세·랭킹의 공개 고스트 자동 선택 버튼을 본인 기록으로 바꾸지 않았다. 공개 상대 API/검증은 후속이다.

실제 앱 메뉴에서 선택할 수 있는 경로를 추가했으며 새 빌드에 반영된다. 이미 설치된 앱을 자동 갱신하거나 실제 기기 설치·실주행을 수행한 것은 아니다. 기존 시작 승인 PR은 수정하지 않았고 이번 작업도 커밋·푸시·PR을 진행하지 않았다.

## 사용 흐름

1. 달리기 → 고스트 대결을 선택한다. 코스가 없으면 기존 C8 코스 선택(최근 달린 코스/내 주변/검색)으로 이동한다.
2. ‘내 완주 기록 선택’을 누른다. 현재 계정과 코스로 기존 run course 준비 API를 호출해 서버 경로 버전을 확보한다. 이 단계에는 위치 측정·START·ghost/start·course/start·도전 수 이벤트가 없다.
3. `/run/own-ghost-select`의 기존 C9 선택 화면에서 내 최고/최근/과거 완주를 선택한다. 목록 기간·페이지·선택 시 품질 검증은 기존 OwnGhostController/OwnGhostSelectionView를 재사용한다.
4. ‘이 고스트와 대결하기’로 준비 화면에 돌아온다. 선택한 내 기록의 코스 총 소요시간을 보여준다. 코스·적합한 상대가 모두 있어야 ‘고스트 대결 시작’이 활성화된다.
5. 준비 화면에서는 짧게 눌러 기존 출발점 지도(C11/C12)로 이동한다. 출발점 반경 안에서 1초 누르기 → 3초 카운트다운 → ghost/start 승인과 기기 저장 → 기존 측정 화면이다. 최초 준비와 동일한 세션 ID/코스 스냅샷을 재사용하며 별도의 course/start는 보내지 않는다.
6. 측정 화면에는 고정한 ‘내 기록 mm:ss’를 표시한다. 일시정지·코스만 종료·완주 안내·동일 세션 자유 러닝 전환·종료 업로드는 기존 경로를 사용한다.

정책 근거는 공통 6(개인 기록·공개 후보 진입점 구분), RUN-01/02/04/05, RCR-01, 9.1 및 기존 개발 계획 P1의 준비→출발점→시작 조작이다. 새 완주·승패·보존 규칙을 추가하지 않았다. 고스트 자료는 기존 보존 정책을 따르며 임의 기간 만료를 두지 않는다.

## 상태와 계정 경계

- 코스 변경은 선택한 상대와 준비 스냅샷을 폐기한다. 자유 러닝/일반 코스로 바꾸면 상대를 해제하고, 일반 코스 전환에서는 고른 코스를 유지한다.
- 선택 화면은 현재 계정·코스 객체와 준비 세대를 확인한다. 계정·코스 변경 또는 dispose 뒤 늦게 도착한 준비/재생 응답은 새 선택을 복원하지 않는다. 빈 후보·불량 재생·통신/코스 오류에는 시작을 허용하지 않고 재시도를 제공한다. 임의 상대 대체는 없다.
- 진행 중·출발 준비 중·시작 승인 확인 중에는 새 고스트 선택을 허용하지 않는다. 선택 경로로 직접 들어와도 기존 달리기 화면으로 복귀한다. 진행 중인 러닝을 새 세션으로 바꾸지 않는다(RUN-05).
- 승인 응답 유실 상태에서는 ‘같은 고스트 시작 확인’으로 기존 원장의 시작을 확인한다. 출발점 화면의 일반 취소/새 시작으로 우회하지 않는다. 확인 재시도에는 새 출발점 반경/새 카운트다운을 요구하지 않고 기존 복구 흐름을 사용한다. 기존 60초 재개 기준을 바꾸지 않았다.
- 출발점 안내도 고스트 대결로 표시한다. 구간 종료 이후에는 기존 자유 러닝 안내를 사용한다. 상대가 먼저 도착했다는 이유로 패배를 표시하거나 자동 전환하는 로직을 추가하지 않았다.

## 파일과 공유 범위

- 새 화면: `ghost_prep_view.dart`, `own_ghost_selection_screen.dart`. C1 구성은 기존 준비/코스 카드/기록 카드 부품을 재사용하며 새 Figma 대조 완료를 주장하지 않는다.
- 기존 `course_run_entry`, `RunController`, `FreeRunController`, FreeRunScreen, CourseRunPrep, CourseStartView, FreeRunLiveView에 준비 상태·상대 표시를 연결한다. 별도 측정기·지도·시계·완주 판정기를 만들지 않는다.
- 공통 라우터에는 개인 선택 경로 하나를 추가했다. MainShell은 출발점 지도에서도 하단 탭을 숨긴다. core/인증/네이티브/서버/DB 마이그레이션은 이번 단계에서 추가 수정하지 않았다.
- 좁은 화면 검증에서 기존 자유 러닝 준비 카드의 문구가 넘쳐 제목/설명 표시 줄 수를 제한했다. 측정·저장 값은 바꾸지 않는다.
