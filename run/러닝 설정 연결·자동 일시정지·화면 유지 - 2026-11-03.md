# 러닝 설정 연결·자동 일시정지·화면 유지

기준일: 2026-11-03 · Asia/Seoul

F4의 오디오 안내·고스트 격차 음성 안내·자동 일시정지·화면 항상 켜기를 실제 러닝 설정과 연결한다. 저장 성공 후 화면과 엔진을 갱신하며 실패 시 기존 상태를 유지한다.

## 설정 계약과 저장

- 공개 진입점: `FrontEnd/app/lib/features/run/run_settings_events.dart`, 수신 메서드: `RunController.receiveSettings(RunSettingsChanged)`.
- 이벤트의 `owner`는 현재 로그인·연결 계정과 일치해야 한다. `enabled`, `unit`, `distanceKm`, `timeMinutes`, `ghostGapEnabled`, `autoPauseEnabled`, `keepScreenOn` 중 변경한 필드만 보내고 생략값은 보존한다.
- `RunSettings`는 기존 `run_settings`의 JSON payload에 저장한다. `RunVoiceSettings`, `RunVoiceSettingsChanged`, `RunVoiceSettingsEvents`, `runVoiceSettingsEventsProvider`는 기존 통합과 동일 타입·provider를 가리키는 호환 이름으로 유지한다. 서버 통신·DB 마이그레이션은 추가하지 않는다.
- 기존 저장 자료에 없는 자동 일시정지·화면 항상 켜기·고스트 격차 선택값은 OFF다. 전체 음성을 꺼도 별도 선택값은 보존한다. 오디오 시트는 음성 관련 필드만 부분 갱신하므로 화면 유지·자동 일시정지·고스트 선택값을 덮어쓰지 않는다.
- F4는 저장 중 관련 설정 입력을 잠근다. 저장 실패는 스위치를 이전 값으로 유지하고 재시도 가능 상태로 돌린다. 다른 계정의 지연 이벤트는 적용하지 않는다.

## 자동 일시정지

사용자가 선택한 10초 정지 기준이다. 정확도 15m 이내의 정상 GPS 표본 3개 이상과 10초 연속 정지를 확인한다. 위치는 2~4m의 작은 범위에 머물러야 하고, 신뢰할 수 있는 이동 속도가 있으면 정지로 보지 않는다. GPS 공백·불량·위치 점프·긴 수집 간격은 후보를 초기화한다.

새 PAUSE 이벤트는 확인 시점에만 기록한다. 확인 전 10초를 소급 차감하지 않는다. 기존 GPS 수집은 유지하고 이동 확인 시 `RunAutoResume`를 사용한다. 달린시간·거리·음성은 기존 일시정지 규칙을, 총 소요시간·고스트 재생·승패 비교는 기존 계속 흐르는 시간 축을 사용한다. 스위치를 꺼도 이미 일시정지된 세션을 임의로 재개하지 않는다.

## 화면 항상 켜기

설정 ON + 진행 중 세션(일시정지 포함) + 현재 계정 + 앱 전면일 때만 Android `FLAG_KEEP_SCREEN_ON`을 적용한다. 준비·결과 화면의 유휴 세션에는 적용하지 않는다. 앱 배경·화면 잠금·러닝 종료·계정 변경·컨트롤러 종료 시 해제한다. Android Activity의 pause/cleanup에서도 해제해 Dart 처리가 늦어져도 유지되지 않게 한다. 물리적으로 꺼진 화면을 깨우거나 휴대폰 전역 설정을 변경하지 않는다.

화면 요청은 순서대로 적용하고 최신 원하는 상태를 기준으로 처리한다. 화면 유지 오류는 기록 측정·기기 저장을 중단시키지 않는다. 센서용 CPU wake lock 및 백그라운드 GPS 수집과 별개다.

## 검증 범위

F4 스위치 ON/OFF·전체 음성 종속·기존 값 보존·저장 실패/중복 입력·좁은 화면, 실제 GPS 수신에서 자동 일시정지 연결·시간 축·이동 재개·공백/불량 억제, 계정별 저장·재시작 복원, 앱 생명주기·종료·계정 변경·지연 화면 요청을 자동 검증한다. 실제 휴대폰의 화면 잠금·배터리 모드·한국어 음성 출력과 야외 GPS 조건은 실기기 확인 대상으로 남는다.
