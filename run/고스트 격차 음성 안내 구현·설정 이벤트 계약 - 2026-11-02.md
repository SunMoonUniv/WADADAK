# 고스트 격차 음성 안내 구현·설정 이벤트 계약

기준일: 2026-11-02 · Asia/Seoul

정책 근거: `정책 문서.md` 제3부 7.4 AUD-05·AUD-07, 9.2·9.5·9.6.

## 구현 범위

- 러닝 모듈에 설정 이벤트 수신·계정별 기기 저장·음성 안내를 구현한다. MY/F4 화면, 스위치, 기존 마이페이지 이벤트 발행부는 수정하지 않는다. 실제 F4 화면의 기존 이름 변경과 스위치 연결도 MY 담당의 후속 작업이다.
- 공개 이름 상수는 `ghostGapVoiceSettingLabel`이며 값은 `고스트 격차 음성 안내`다. MY 연결 시 이 이름을 사용한다.
- `RunVoiceSettings.ghostGapEnabled`는 기본 `false`이고 이전 저장 자료에 필드가 없어도 `false`다. 전체 음성을 꺼도 이 선택값은 보존한다. 재생은 두 설정이 모두 켜졌을 때만 허용한다.
- 기존 거리(1·2·5km) 또는 세션 달린시간(5·10·15분) 안내 뒤에 현재 시간 격차 한 문장을 붙인다. 별도 주기·추월 음성·거리 격차 대체·실시간 서버 통신은 추가하지 않는다.
- 화면과 음성이 기존 동일 위치 최초 정방향 도달 시간 차이 계산을 공유한다. 코스 및 자유 기록 기반 대결에 적용하고 원본·서버 승패·화면 반올림은 변경하지 않는다.
- 5초 미만은 ‘고스트와 거의 나란히 달리고 있어요.’, 그 이상은 절댓값을 가장 가까운 5초 단위로 반올림하여 앞섬/뒤처짐을 말한다. 반올림 경계의 정중앙은 큰 값이다.
- 이탈 후보·확정(이번 러닝의 경고 음소거와 무관), 오래된/불량 GPS, 재개 후 새 위치 없음, 고스트 재생 공백·대응 불명확에서는 격차만 생략한다. 유효한 정기 안내는 유지하고 지난 격차를 재생하지 않는다.
- 완주 → 이탈 확정 → 이탈 후보 → 정기 안내와 격차 순으로 처리한다. 높은 우선순위가 진행 중인 안내를 대체하면 남은 문장을 보충하지 않는다. 완주·코스만 종료 등 대결 마감과 자유 러닝 전환 시 대기 안내를 취소한다. 일시정지·계정 변경·러닝 종료도 재생을 중단한다.
- Android 음성 완료 및 오디오 포커스 상실을 Dart에 알려, 낮은 우선순위 안내가 재생 중인 경고·완주 음성을 끊지 않게 한다. 음성 엔진 실패는 기록 측정을 중단하지 않는다.

## MY/F4 후속 연결

공개 진입점은 `FrontEnd/app/lib/features/run/run_voice_settings_events.dart`다. MY의 내부 타입을 러닝이 가져오지 않으며 공통 모듈·서버 API·DB 변경이 없다.

설정 UI에서는 전체 음성이 OFF이면 격차 스위치를 비활성화하고 `음성 안내를 켜면 사용할 수 있어요`를 표시한다. 표시명은 `ghostGapVoiceSettingLabel`을 쓴다. 전체 음성을 OFF로 바꾸는 이벤트에 `ghostGapEnabled: false`를 함께 넣지 않는다.

```dart
import 'package:wadadak/features/run/run_voice_settings_events.dart';

// F4 담당 구현 시 연결할 예시. 이번 변경에는 MY 호출부를 추가하지 않았다.
ref.read(runVoiceSettingsEventsProvider).publish(
  RunVoiceSettingsChanged(
    owner: signedInMemberId,
    ghostGapEnabled: selected,
  ),
);
```

- 이벤트는 변경 필드만 보내는 부분 갱신이다. `enabled`, `unit`, `distanceKm`, `timeMinutes`, `ghostGapEnabled`를 지원하며 생략한 값은 보존한다. 계정 식별자는 필수이고 현재 로그인·연결 계정과 다르면 무시한다.
- `runControllerProvider`가 이벤트 스트림을 구독한다. 이벤트는 순서대로 처리하며 유효한 값을 기존 `saveVoiceSettings` 경로로 저장·적용한다. 계정 전환 중 늦게 도착한 이전 계정 이벤트는 새 계정에 적용하지 않는다.
- 저장 완료/실패를 UI에서 직접 확인해야 할 때는 공개 수신 메서드 `await ref.read(runControllerProvider).receiveVoiceSettings(event)`를 사용할 수 있다. 정상 적용은 `true`, 다른 계정·종료 상태는 `false`, 잘못된 값·저장 실패는 예외다. 스트림 수신 경로는 오류를 잡아 안내하고 이후 이벤트를 계속 처리한다.
- 설정 변경 시 현재까지의 거리·시간 기준점을 소비하고 다음 정상 간격부터 안내한다. 지나간 안내를 재생하지 않는다. 격차를 끄면 격차가 붙은 정기 안내의 남은 부분을 중단하되, 이미 재생 중인 이탈·완주 음성은 유지한다. 전체 음성을 OFF로 바꾸면 이탈·완주 음성도 중단한다. 재시작·계정 재연결 시 계정별 저장값을 복원한다.
- 기본 OFF이므로 MY 발행부가 연결되기 전에는 일반 앱 사용 중 격차 음성이 자동 활성화되지 않는다. 테스트는 공개 수신 경로로 활성화해 실제 대결 흐름을 검증한다.

## 검증 범위와 후속 확인

자동 테스트는 이전 설정 호환·계정별 저장·계정 전환 지연 이벤트·부분 갱신·거리/시간 주기·반올림 경계·완주/이탈 우선순위·중복/대기 억제·GPS 생략·코스/자유 기록 대결 연결을 포함한다. 실제 한국어 TTS의 청취 품질, 음악·이어폰·화면 잠금 상태 및 GPS 환경에서의 표현 간격은 실기기 야외 인수 대상으로 남는다.
