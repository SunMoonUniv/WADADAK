## 동작

- 주행·일시정지 중의 지도에만 `1 km`, `2 km` 등을 추가한다. 등록 코스의 미리 정해진 표지가 아니라 이미 확인된 총 주행 거리 기준이다.
- 확인된 비단순화 경로의 각 인접 좌표 사이에서 같은 m 산식으로 누적하고, 해당 구간 내부에서만 거리 비율로 표지 위치를 정한다. 반올림 전 확정 거리와 존재하는 경로를 모두 충족해야 표지를 만든다.
- 예: 정상 900m → GPS 공백/재개 → 정상 200m이면 첫 표지는 재개 후 정상 구간의 100m 지점이다. 공백의 양 끝을 선으로 잇거나 거리를 더하지 않는다.
- 같은 길 왕복·반복도 실제 거리대로 누적하고 km 번호별 ID를 사용한다. 일시정지·지도 재표시·복구 후 같은 경로에서 재현하며 새 러닝은 새 경로로 초기화한다.
- 기존 `MapView`·`MapMarker`·`WdKmMarker`를 사용한다. 결과/기록 상세 지도는 기존 출발·종료 표지를 유지한다. 코스 이탈은 다른 담당이 구현하며 이번 변경에 포함하지 않는다.
- 원본 입력·SQLite·서버 API·거리·시간·자동 랩·음성·고도·버전·랭킹/완주 판정은 변경하지 않는다.

## 검증 범위

- 계산/실제 PACE_V3 재생 12개: 1km 직전/정확한 경계·여러 km·거리/경로 부족·중복/불량 좌표·왕복·경도 경계·GPS GAP/정지/큰 튐/긴 공백/불량 정확도·복구와 랩 일치·원본 불변.
- 실제 화면 3개: 320px·402px에서 1→2km 갱신·다음 km 미표시·정지 중 유지·새 세션 초기화·경로 분리, 결과 지도 기존 표지 유지. 화면 PNG로도 확인한다.
- 러닝 회귀 전체 및 정적 검사, Android debug APK 빌드를 확인한다. 서버 소스는 변경하지 않아 서버의 직전 120개 검증 기록과 구분한다. 실제 야외 GPS 지도 표시·장시간 주행 검증과 운영 배포·휴대폰 설치는 별도다.
