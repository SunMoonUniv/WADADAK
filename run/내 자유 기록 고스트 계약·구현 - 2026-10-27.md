## 사용 흐름과 범위

달리기→고스트 대결→내 자유 기록 선택→경로·대결 비교 시간 확인→이 기록과 대결하기→출발점 안내→기존 시작 조작·카운트다운→측정·고스트 재생/격차→종료·서버 결과로 연결한다. 앱 내부 선택 경로는 `/run/free-ghost-select`다. 기존 코스의 내 완주 기록 선택도 유지한다.

목록은 본인 서버 처리 완료 기록을 실제 `startedAt DESC, id DESC`로 보여준다. 전체/이번 달/이번 주 필터는 Asia/Seoul 기준이다. 서로 다른 경로의 최고·평균 기록은 만들지 않는다. 1km 미만도 비활성 사유를 표시하며 원본 개인 목록에서 삭제하지 않는다. 자유 대결로 남은 기록도 코스 시도가 없는 자유 기록이면 같은 조건으로 다시 선택할 수 있다. 과거 대결 결과를 다시 쓰지 않는다.

Figma C9 `1453:4494`의 디자인 컨텍스트·스크린샷을 확인하고 기존 WdRankRow·WdRecordCard·WdInfoBanner·WdButton·지도·글꼴/아이콘을 재사용했다. 선택 UI에 원래 기록 시간과 대결 비교 시간, 중단 여부·거리 제한·재생 불가 사유를 표시한다. 계정 변경·화면 이탈·기간 변경 후 늦게 온 응답은 선택을 확정할 수 없다.

## 원본 검증과 P1~P4

1. 본인 소유·서버 DONE·미삭제이며 등록 코스 시도가 없는 기록이어야 한다. 다른 회원·처리 중·미업로드 기록은 신규 선택/승인할 수 없다.
2. 원본 한 기록의 서버 검증 `metrics.distanceM >= 1000`을 그대로 비교한다. 화면 반올림·여러 기록 합산·공백 직선 연결을 사용하지 않는다. 중단 종료 사유를 정상 종료로 바꾸거나 정상 종료만 허용하지 않는다.
3. 저장 원본으로 기존 FreeRunCalculator를 다시 실행해 거리·총 소요시간과 계산 버전 일치를 확인한다. 기존 legacy(null), PACE_V1/V2/V3 입력을 지원한다. 누락·불일치·지원하지 않는 형식은 재생 불가로 반환한다. 원본 저장값을 갱신하는 작업은 아니다.
4. 신뢰 가능한 GPS 조각을 순서대로 보존하고 조각 사이에 `breaks`를 둔다. 미수집 구간을 연결하지 않는다. 기준 경로의 끝은 저장 범위의 마지막 재현 가능한 경로 끝이다. 조각 하나의 점이 부족해 선분을 만들 수 없으면 경로 길이를 보충하는 데 사용하지 않는다.
5. 기존 서버 추적·인정 거리 판정기로 원본에도 같은 방향·순서·출발/끝·95% 조건을 재현한다. 최초 완주까지 총 소요시간을 별도 산출하며 정지·시작 후 대기를 포함하고 이후 종료 대기는 제외한다. 재현할 수 없으면 선택 불가다.
6. 비교 구간에서 수동 정지를 제외한 연속 공백 ≤30,000ms, 누적 공백 ≤비교 구간의 수동 정지 제외 시간×5%를 모두 요구한다. 10초 초과 GPS 연결 금지는 그대로다. 숫자를 만족해도 위치·정지·끝 재현이 안 되면 허용하지 않는다.
7. 60초 초과로 재개하지 못했던 중단 원본도 위 조건을 통과하면 새 대결 원본이 된다. 같은 세션의 60초 재개 제한·기존 대결 판정은 변경하지 않는다.

현재 새 대결의 GPS 공백 길이만으로 자동 패배/무효를 추가하지 않는다. 새 주행은 기존 판정기에 저장된 기준 경로를 넣어 서버가 최종 판정한다. 원본 선택 1km와 새 주행 완주 95%는 별개다.

## API

아래 경로의 공통 접두사는 `/api/v1/runs`다. 기존 JWT·ApiResult·RunErrorCode를 사용한다. 소유자는 토큰 subject에서 정하며 요청 회원 ID를 신뢰하지 않는다.

| 요청 | 응답/동작 |
| --- | --- |
| `GET /ghost-candidates/own/free?period=ALL&size=20&cursor=...` | `content`, `nextCursor`. 각 후보는 id·실제 시작/등록 시각·종료 사유·원본 거리/시간·`distanceEligible`. 거리 외 정밀 검증은 선택 때 수행. size 1~50, 커서는 기간 범위에 귀속 |
| `GET /records/{id}/free-ghost-playback` | `playback`, `originalDistanceM`, `originalElapsedMs`, `endReason`, `referenceHash`. playback은 기존 재생 구조와 `GHOST_PLAYBACK_FREE_V1`, 적합성·사유·공백 품질·기준 경로/조각·원본 비교 시간·위치/정지/공백 자료 |
| `POST /sessions/{id}/ghost/start` | `courseId:null`, `courseVersion:1`, `sourceRecordId`, `startedAt`, `playbackVersion:GHOST_PLAYBACK_FREE_V1`, `referenceHash`로 요청. 서버 재검증 후 `GHOST_START_FREE_V1` 승인 |
| `GET /sessions/{id}/ghost/start` | 저장된 자유/기존 코스 고스트 승인 조회. 응답 유실 후 재확인용 |
| `GET /sessions/{id}/ghost/result` | 본인 전용 불변 `GHOST_RESULT_FREE_V1` 결과. WIN/LOSE/DRAW/INVALID·이유·비교 정수 초/원본 ms·확정 시각 |

기존 등록 코스 요청은 기존 코스 ID·버전·`GHOST_PLAYBACK_V1`을 사용한다. 코스 ID를 지워 기존 시도를 자유 대결로 바꾸지 않는다. `CourseSnapshot`은 run 내부에서 재사용하는 경로 DTO 이름이며 자유 대결의 `courseId`는 null이다. 새 경로 버전 1은 등록 코스 버전이나 코스 존재를 뜻하지 않는다. 기존 DTO에서 `breaks` 생략은 빈 배열로 해석한다.

`referenceHash`는 서버가 만든 준비 재생 자료의 SHA-256이다. 시작 직전에 원본/기준 경로가 달라졌으면 CONFLICT, 자료가 부적합하면 GHOST_UNAVAILABLE, 소유권·삭제/탈퇴 등 조회 불가는 NOT_FOUND를 반환한다. 준비 응답의 재생 불가 사유에는 DISTANCE_BELOW_1000M, NOT_FREE_RECORD, MISSING_SOURCE_INPUTS, REFERENCE_NOT_REPRODUCIBLE 및 기존 공백/위치 사유가 있다. 후보의 거리 적합성을 최종 재생 승인으로 사용하지 않는다.

기존 회원→세션 잠금 안에서 승인·새 세션을 원자적으로 저장한다. 최초 승인 전에는 원본을 재검증하며, 승인 뒤 동일 요청 재시도는 저장 승인을 먼저 반환한다. 원본 삭제 후 재시도도 상대를 바꾸지 않는다. 시작 시각·원본·버전·해시가 다른 요청은 충돌이다. CourseApi 조회나 코스 준비/시작 이벤트는 수행하지 않는다.

## 저장·판정·복구

새 마이그레이션 `V20261027_2100__run_free_ghosts.sql`은 `run.free_ghost_starts`와 `run.free_ghost_results`를 추가한다. 승인→sessions, 결과→승인에만 같은 run 스키마 FK/연쇄 삭제를 둔다. 원본 기록 FK·가짜 코스·다른 모듈 FK·기간 만료는 없다. 기존 코스 승인/결과 테이블과 저장 자료는 유지한다.

서버는 고정한 기준 경로·breaks로 기존 판정기를 호출하고 기존 GhostDuelJudge의 승패/미완주 규칙을 재사용한다. 비교용 내부 CourseOutcome은 외부 Result.course나 코스 이벤트로 내보내지 않는다. 자유 대결의 `Result.course`는 null이고 `Result.ghost`에 결과를 저장한다. 정상 개인 거리·거리 이벤트는 기존 경로로 반영하며 코스 도전/완주/랭킹/리뷰/유지 기간 자격은 만들지 않는다. 공용 `courseElapsedSeconds` 결과 필드는 FREE 버전에서 기준 경로의 비교 시간이다. 정수 초 변환에 관한 D-13의 합의 상태는 바꾸지 않는다.

양수 거리의 개인 기록·대결 결과·등록 이벤트·DONE은 같은 처리 트랜잭션으로 확정한다. 유효한 0거리 종료는 기존 ZERO_DISTANCE 상태와 일반 기록 제외를 유지하면서 대결 요약만 저장한다. 앱은 이 경우 전용 `/ghost/result`로 판정을 읽어 종료 화면에 표시하고 일반 개인 목록에는 추가하지 않는다.

SQLite v4·GHOST_DEVICE_V1에 선택 referenceHash, null 코스 ID, FREE 승인/재생 버전과 경로 조각을 보존한다. 기존 코스 기기 JSON은 호환된다. 마지막 저장 후 같은 부팅의 신뢰 가능한 경과시간 0~60,000ms이면 같은 시작/상대/입력 순번으로 재개한다. 중단 구간은 PROCESS_RECOVERY GAP으로 남기며 거리·GPS를 보충하지 않는다. 초과·재부팅·불명확한 시계는 기존 중단 마감 절차를 따른다. 자유 대결은 코스용 segmentEnd 재전송 신호를 만들지 않는다.

지도는 조각 사이를 잇지 않고 고스트 위치와 거리/시간 격차를 보여준다. 시간 격차는 러너 현재 경로 누적 위치에 양쪽이 최초 정방향 도달한 총 소요시간 차이다. 역행·공백·대응 불명확·오래된 GPS는 계산할 수 없는 격차를 `—`로 표시한다. 최종 승패는 업로드 후 서버 결과를 사용하며 대기·다시 확인 동작을 제공한다.

본인 기록 삭제·탈퇴는 기존 잠금/삭제 예약/늦은 응답 차단을 유지한다. 본인 세션 삭제는 자유 승인·결과도 정리하고 원본 삭제는 이미 승인된 다른 대결을 지우지 않는다. 상세 30일 만료 등 별도 보존 기간은 추가하지 않는다.
