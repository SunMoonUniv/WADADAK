# 1번 담당 F5 — 1·2단계 구현

이번 단계는 **실제 러닝 기능의 기반을 만드는 작업**이다. 실기기 주행을 먼저 요구하지 않는다.

## 이번에 동작하는 것

- 달리기 탭 → 1초 누르기 → 3초 카운트다운 → 측정 시작.
- 카운트다운 취소는 UUID·입력 기록을 만들지 않는다.
- 일시정지 중 총 소요시간은 흐르고 달린시간은 멈춘다. 재개와 종료 확인을 제공한다.
- 홈·다른 탭에 다녀와도 앱 내 측정은 유지된다.
- 종료하면 시간 결과 한 건이 메모리에 남으며 새 러닝을 준비할 수 있다.
- 가짜 GPS로 거리·페이스·순번·정지 중 이동 제외·GPS 공백을 검증한다.

GPS 권한·실제 위치 수집·SQLite·서버·지도·코스·고스트는 아직 연결하지 않았다. 실제 화면에서는 시간을 기록하고 거리는 ‘—’로 표시한다. 기록은 메모리뿐이므로 앱 종료·로그아웃 시 사라진다. 결과를 기기에 저장했다고 표시하지 않는다.

## 읽을 코드 순서

| 순서 | 파일 (`FrontEnd/app/` 기준) | 이해할 내용 |
| --- | --- | --- |
| 1 | `lib/features/run/domain/run_models.dart` | 상태, 단일 순번 입력, 결과 스냅샷, 단위 |
| 2 | `lib/features/run/domain/free_run_session.dart` | 준비→측정→정지→재개→종료, 시간·거리 계산 |
| 3 | `test/run/free_run_session_test.dart` | 120초/정지20초의 검토된 기대값, 가짜 GPS |

| 5 | `lib/features/run/presentation/free_run_screen.dart` | 상태에 맞는 화면과 버튼, 종료 확인 |

화면은 컨트롤러를 호출하고, 컨트롤러는 세션을 변경한다. **시간 계산은 화면과 타이머에 넣지 않는다.** Stopwatch는 단조 증가하는 기준을 제공하고, 화면 갱신 타이머는 1초마다 다시 그리기만 한다. 위젯이 숨겨져도 실제 지난 시간을 계산할 수 있다.

## 공통 계약 초안

- 시작 후 기기 UUID 하나를 유지한다. 카운트다운 취소 전에는 생성하지 않는다.
- START/GPS/PAUSE/RESUME/GAP/END를 세션의 단일 seq로 기록한다.
- 입력 시간은 원본 ms, 절대 시각은 UTC다. START는 0ms다.
- 평균 페이스는 총 소요시간 기준 초/km. 거리 0이면 null/‘—’.
- GPS 품질 초기값: 정확도 30m 이하, 입력 간격 15초 이하, 12m/s 이하. 개발용 값이며 실주행 보정 전이다.
- 정지·재개·GAP·나쁜 GPS 전후를 거리로 연결하지 않는다. 재개 뒤 첫 위치는 새 기준점이다.
- 합성 첫 샘플: 총120초, 40~60초 정지, 달린시간100초. 정지 중 이동을 제외한 거리 약22.239016m.
- 이 단계의 입력 JSON을 2번과 리뷰한 뒤 SQLite·업로드 계약을 확정한다.

화면에서는 달리기 탭에서 1초 눌러 시작하고, 정지 중 두 시간을 비교한다. 종료 확인의 취소·확정, 홈에 갔다 돌아오는 경우도 확인한다. 자동 테스트는 120초를 실제 기다리지 않고 가짜 시계를 진행시킨다.
